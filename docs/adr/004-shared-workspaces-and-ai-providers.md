# Shared workspaces, simple accounts and provider adapters

Status: accepted. Supersedes ADR-003’s invitation-only registration/private-only workspaces and prior local-only AI restriction. The application remains accessible only on the installation computer.

Registration uses a unique case-insensitive username and password. One transaction serializes registration with administrator lifecycle changes and promotes only the first account. Password hashes and existing sessions are preserved. Display name initially matches username; timezone detection supplies initial workspace defaults silently. Account invitations are retired; existing links lead to signup. Recovery and suspension remain administrator operations.

A Workspace retains one canonical owner. WorkspaceMember records assign editor/viewer roles to existing accounts; the owner role is derived from Workspace.ownerId and cannot be granted through membership mutation. A workspace with no members is private. The authorization module resolves current role from persisted membership, owner/account lifecycle and session state. Its interface is reused by HTTP guards, the mandatory persistence fence and managed storage. Writes need editor access; membership, settings, trash and credential-bearing backups need owner access. SSE re-resolves read permission on every poll. The installation administrator role never bypasses workspace membership.

Runs act under persisted workspace authority, so removing an editor does not interrupt previously authorized automation. Owner suspension/workspace trash stops automation. Managed files and composite database constraints retain workspace isolation. Browser backup restore creates a private workspace and excludes memberships and installation OAuth developer credentials.

The AI module keeps text operations and workflow compilation behind one interface. Real adapters implement transport and model discovery for Gemini, Ollama and OpenAI. One resolver supplies workflow defaults and step overrides to both validation and execution; switching providers does not inherit another provider’s model or connection. Immutable published definitions and list scope snapshots retain AI choices. Legacy definitions with no AI settings retain Ollama behavior. Import/export and backup restoration rewrite AI connection references recursively.

Cloud requests require a public-demo data policy. Private workflows use explicitly selected Ollama. API keys are encrypted Connection credentials. No automatic provider fallback or billing upgrade exists. One shared AI lease is retained; provider/model/token counts/duration/outcome are recorded without storing prompts in usage records. Usage counters cannot determine or guarantee a provider’s billing tier. Ollama reachability no longer gates startup.

The connector module pairs catalog definitions with provider execution and resource selectors. Metadata classifies reads/writes and retry safety before execution; previews simulate writes. Provider transport errors preserve uncertain write outcomes, including a lost response body and database query timeouts. Outlook’s empty 202 response is a completed send. External databases use parameterized structured queries, bounded reads/updates, original TLS hostname verification and a pinned TCP destination. PostgreSQL bounded updates match (tableoid,ctid), including partitioned tables. Installation destinations are denied across IP aliases and Docker host gateways.

Installation OAuth developer secrets stay in AppCredential. A workspace stores an installation-reference marker; connection resolution combines credentials only in server memory. Token refresh persists the reference and tokens, without copying the shared client secret into workspace storage/backups. Legacy per-connection OAuth applications remain supported. Google connection testing validates requested scopes without requiring unrelated Drive permissions for Sheets-only accounts.

These are deepening changes to existing modules: the adapters are real variation points, while authorization, AI choice resolution and effect classification retain locality. Tests exercise the caller-facing interface and real persistence rather than duplicating implementation details.
